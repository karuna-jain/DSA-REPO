Two Sum

Pattern: Two Pointers LeetCode Link

Problem Statement

Given an array of integers sorted in ascending order, find two numbers such that they add up to a specific target number.

Complexity Analysis

Time Complexity O(N)
Space Complexity O(1)

Approach & Intuition

Place one pointer at the start and one at the end. Calculate the sum. If the sum is smaller than target, increment left. If larger, decrement right.

Pattern Recognition

Since the array is sorted, scanning from both boundaries guarantees we check all relevant pairs in O(N) without redundant O(N^2) inner iterations.

Dry Run Trace

Alternative Approaches

1. **Brute Force**: O(N^2) comparison of all pairs. 2. **Hash Map Lookup**: O(N) time and O(N) space, which is optimal for unsorted arrays.

Company Frequencies

Common Implementation Mistakes

  • Forgetting index overflow boundary conditions.
  • Incorrect pointer increment/decrement logic resulting in infinite loops.
